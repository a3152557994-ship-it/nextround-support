游戏内的数据处理

游戏不要求创建账号，不要求填写真实姓名、电话、邮箱、资产或收入。游戏内的公司、现金、融资、负债与持股均为虚构数据。当前版本不含广告、第三方分析或追踪 SDK，也不会由游戏向开发者服务器发送个人信息或游戏进度。

本地存档和偏好

当前旅程、决策与月报、历史旅程、音效与触感偏好保存在你的设备上，用于继续游玩、恢复进度与查看历史。自动存档保留上一个可读取版本；开始新局会备份上一局文件。游戏内最近完成旅程列表保留 40 局，另外的恢复备份可能继续保存在设备上。我们不运营玩家账号或云端同步服务。操作系统备份与恢复可能处理应用数据，其行为受系统及你的设置控制。

你主动选择的分享

若使用系统分享功能，接收人和接收应用由你选择，相关平台按其自身规则处理分享内容。游戏不会自动向联系人、社交平台或开发者发送任何分享内容。

购买和 Apple 平台信息

应用购买、付款和下载由 Apple App Store 处理，游戏不接收银行卡号码或支付密码。Apple 可能依其政策及你的设备设置，向开发者提供销售汇总、下载统计或崩溃诊断；开发者仅将这些平台提供的信息用于运营和修复问题，不将其用于广告追踪。Apple 自身的数据处理适用 Apple 隐私政策。

支持邮件

如果你主动联系支持，我们会收到你的发件邮箱、邮件正文和你选择发送的附件，用于回复、排查和处理你的请求。邮件由 Gmail 托管。请不要发送与问题无关的敏感资料。问题解决后，不再需要的支持信息将删除；若你希望删除来信或附件，可通过同一邮箱提出请求，法律要求保留的记录除外。

支持网站

本网站由 GitHub Pages 托管，不添加分析脚本、广告或追踪 Cookie。访问时，GitHub 会为安全目的记录访问者 IP 地址及相关请求信息。这属于网站托管服务的数据处理，详情见 GitHub 隐私声明。只在游戏内离线游玩不会访问这个网站；你主动打开外部链接后，相应服务适用自己的隐私规则。

保留、删除和联系

本地进度保留在你的设备上，我们不能远程读取或删除。请按 支持页的数据删除步骤 操作；系统备份可能另有副本。macOS 删除应用文件本身不一定删除其支持目录。有任何数据处理或删除请求，请联系上述邮箱。

未成年人

游戏不要求提供年龄或身份信息，也不提供在线聊天、真实投资、借贷或现金奖励。内容使用简化的经营模拟。适用年龄分级以 App Store 产品页面为准。

政策更新

如果产品功能或数据处理方式变化，我们会相应更新本政策与 App Store 隐私信息，并在需要时获得你的同意。此页面顶部会注明最新生效日期。
